## 🛠️ Getting Started

### 1. Install Dependencies And Start 
    cd frontend
    npm install
    npm run dev

## Deploy on Vercel

- Set **Root Directory** to `frontend`; use `npm run build` and `dist` as the
  output directory.
- Set `VITE_API_URL` to the Render API URL ending in `/api`, for example
  `https://your-api.onrender.com/api`.
